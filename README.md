# 🚗 AI Agent for Audi Car Showroom
An AI-powered virtual showroom assistant designed to help customers explore Audi vehicles through an interactive chatbot experience. The project simulates a real Audi showroom conversation where users can ask about car models, features, specifications, and pricing information.

## 📌 Project Overview
This project demonstrates how an AI chatbot can be used in an automotive showroom environment. The assistant provides customers with quick access to vehicle information and creates a digital showroom experience similar to interacting with a sales representative.

## ✨ Features
- 🤖 AI chatbot that acts as an Audi showroom assistant
- 🚘 Provides information about Audi models such as A3, A4, A6, Q5, Q7, e-tron, and more
- 💰 Displays pricing and feature details
- 📋 Helps customers explore vehicle specifications
- 💬 Simulates a real car sales conversation
- 🌐 Web-based interface built with Flask

## 🛠️ Tech Stack
- **Programming Language:** Python 3.13
- **Framework:** Flask 3.1.0
- **Frontend:** HTML, CSS
- **Backend:** Python, Ollama qwen3:0.6b
